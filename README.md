# FinFlow

Personal finance dashboard with NLU-first inputs, deliberate data-dense UI, and modern full-stack TypeScript.

## Principles
- **Anti-AI-Slop:** Strict adherence to design fundamentals (editorial warmth, purposeful contrast, no generic purple gradients or Inter ubiquity).
- **Practical:** Built to solve real personal money tracking with rapid natural language input and accurate bookkeeping.
